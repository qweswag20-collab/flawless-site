Что внутри скрипта

Всё, что описано ниже, живёт в одном файле и настраивается из меню чит-клиента: страницы Resolver, Visuals и Profiles.

Резолвер без Player List

Работает напрямую с сущностями — ни одного обращения к plist.

  • LBY — главный источник на земле, оригинал восстанавливается
  • Джиттер-центрирование чередующегося eye-yaw (режим в воздухе)
  • Движущиеся цели — направление через velocity
  • Brute force {0, +limit, -limit} по промахам, с защитой от ложных срабатываний

3D-эффекты в мире

Частицы живут в мировых координатах, а не приклеены к экрану.

  • Хит-частицы: сфера, гравитация, затухание, позиция из хитбокса
  • Килл-бурст: золотой взрыв + ударные кольца по 20 сегментам
  • Кап 320 частиц / 8 колец, очистка на round_start

Индикатор у прицела

Только текст и векторное лого — никаких панелей и фонов.

  • Бриллиант с двойным контуром, внутренняя рамка, буква F
  • Статус: резолвер / точность / скорость / киллы
  • При скопе плавный сдвиг в сторону: Left / Right, spring-анимация

HUD

Классический набор в стиле скита, рисуется поверх игры.

  • Ватермарка: пинг, fps, tickrate, время
  • Список кейнбиндов с перетаскиванием за заголовок
  • Шот-фид + консольные логи хитов / промахов / резолвера

Профили

Настройки живут локально и переживают перезапуск.

  • 5 локальных слотов через database.write
  • Импорт настроек старых версий (nexra → flawless)
  • Безопасный apply: валидация и полный откат при ошибке

Self-contained и аккуратный

Код можно читать целиком — он небольшой и commented.

  • Без HTTP, FFI, скачанных модулей и внешних конфигов
  • Вся логика в pcall, трекинг недостающего API
  • Оригинальные углы всегда восстанавливаются
Честно об ограничениях: резолвер эвристический — он правит LBY по наблюдаемым данным и брутфорсит по промахам, а не вскрывает скрытые углы сервера. Эффекты не рисуются за спиной камеры (так и задумано). Скрипт проверен AST-чекерами и API-моком, но не в живой игре — при проблемах смотри консоль ([flawless] ...).

Установка за минуту

Нужен чит-клиент gamesense.pub (skeet) с рабочим Lua API и CS:GO Legacy.

01
Скачай файл

Кнопкой выше — получишь чистый flawless_legacy.lua (v1.4.2). Больше файлов не нужно.

02
Положи в папку lua игры

Например: ...\Counter-Strike Global Offensive\csgo\lua (в Legacy-сборке папка называется csgo legacy\lua).

03
Загрузи в клиенте

В игре открой меню чит-клиента → вкладка LUA, раздел B, выбери flawless_legacy.lua и загрузи. В консоли появится [flawless] Legacy 1.4.2 loaded.

04
Включи мастер

Поставь галку flawless | Enable. Резолвер уже включён по умолчанию; настройка — страницы Resolver / Visuals / Profiles.

05
Сверь хеш (по желанию)

Сравни SHA-256 скачанного файла с хешем на этой странице — так ты точно играешь той версией, что описана здесь.

Changelog

Проект переписывается целиком каждую итерацию — история версий:

1.4.2

Фикс загрузки: возвращён хелпер combo — дропдаун направления скоп-сдвига крашил загрузку скрипта.

1.4.1

Дропдаун направления скоп-сдвига Left / Right; резолвер включён по умолчанию; LBY стал приоритетным источником на земле.

1.4.0

Векторное лого (бриллиант + F) и текст-only индикатор у прицела с плавным сдвигом при прицеливании.

1.3.0

AA-билдер и Manual AA удалены (анти-аим настраивается в самом ските). Добавлены мировые 3D-эффекты: хит-частицы и килл-бурст с ударными волнами.

1.2.0

Полностью переписан резолвер без Player List: LBY / eye angles / velocity / choke-детект, brute force по промахам. Новая ватермарка.

1.1.0

Первая версия: state-based анти-аим и резолвер на Player List (теперь доступен только как legacy-путь импорта настроек).
